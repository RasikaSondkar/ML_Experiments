Project Background & Motivation

Academic Context

During regular Machine Learning laboratory coursework, students typically build and evaluate models in isolated Jupyter notebooks or individual standalone scripts. While each algorithm functions independently, evaluating multiple models requires switching between numerous environments, script files, and command-line scripts.

The Integrated Machine Learning Algorithm Dashboard brings together all 10 laboratory experiments into a single, cohesive, web-based dashboard. It enables students, peers, and laboratory examiners to run live predictions on new inputs, inspect underlying dataset characteristics, review verified performance metrics, and visualize decision spaces in real time.

1. Model Reusability

All models originate from actual laboratory experiments and are loaded from pre-trained serialization bundles (.pkl and .joblib). No models are artificially recreated or retrained unnecessarily.

2. Authentic Metrics

Performance metrics—including R², MAE, RMSE, Accuracy, Precision, Recall, and F1-score—are computed directly against the complete original datasets using Scikit-learn evaluation utilities.

3. Reproducibility & UI

The user interface uses a minimal academic design with Bootstrap 5 and custom CSS. A 1-click sample value loader allows instant testing of complex multi-feature models during viva demonstrations.
